# Shadow DIGIT 接触面积变化率离线对照：2026-10-24

## 结论

在现有成功专家轨迹上，加入接触面积变化率改善了力回归，尤其是初触阶段。
10 个留出 seed 的接触帧 MAE 均下降。当前证据支持继续验证这一特征；尚未验证
CaP-X 的不同初触姿态和 60 Hz 运行，也没有替换运行时模型。

## 数据与方法

- 来源：`/mnt/data/ljz/opentacbench/shadow_digit_force_v1/balanced_50seed_v1/episodes`。
- 50 条原生成功专家轨迹；seed 3100–3139 训练，3140–3149 完整留出。
- 原有 48,064 个任务对齐帧；每条首帧缺少历史，从两组中共同排除，共 48,014 帧。
- 留出集 9,623 帧，其中实测力至少 0.1 N 的接触帧 3,248，初触帧 240。
- 深度 30 Hz，私有真实琴键顶部接触力 240 Hz；按实际 physics_step 精确对齐。
- 两组使用完全相同的训练帧，沿用每 episode、每 0.1 N 力区间至多 30 帧的抽样。
- 黑白键分别回归，训练集 Median/IQR 归一化，线性及逐元素平方项，ridge alpha 固定为 0.01。
- 不用机器人关节状态、腕部高度、目标轻重音或目标牛顿数作输入。
- 真实力和原生进度只用于离线标签对齐、训练抽样及指标分组；没有进入触觉特征。
- 不裁剪回归结果；质量门控与原始回归误差分别报告。
- 两组未调超参数；已有留出集曾用于历史审计，不能称为全新盲测。

### 特征

4D：`mean_mm, area_gt_0p01mm, area_gt_0p05mm, area_gt_0p2mm`，与当前运行时计算契约一致。

5D：原 4D 加上 `area_gt_0p05mm_rate_per_s`：

```text
A(t) = 有效像素中 |reference_depth - depth| > 0.05 mm 的像素比例
rate(t) = [A(t) - A(t - 1/30 s)] / (1/30 s)
```

只读当前与过去的公开深度。在 240 Hz 物理时钟中历史距离为 8 步；
30 Hz 为前一个采样，60 Hz 应为前两个采样。不插值、不借用未来帧，缺历史即不可用。

- 初触 MAE 下降 80.4%，白键重音初触下降 82.7%，接触总体下降 53.0%。
- 10/10 留出 seed 的接触 MAE 改善。按完整 seed 配对 bootstrap 的平均差值
  `5D - 4D = -0.003091 N`，95% 区间约 `[-0.003181, -0.002996] N`。
  该区间只描述现有专家 seed，不能推断跨姿态泛化。
- 两组留出 OOD 均为 0，接触帧不可用均为 0；无接触误报≥0.1 N 均为 0。
- 各 seed 的最小对齐误差延迟均为 0；未对预测作时间平移。
- 释放 P95 略升；无接触原始回归误差增加。5D 在释放后的个别无接触帧可产生
  约 -0.11 N 的原始回归输出，未裁剪；沿用现有门控时不作为有效牛顿值输出。
- 留出集中仅有 1 个超过对应任务力带上限的帧，不能据此验证超力检测可靠性。
- 重拟合 4D 与现有冻结 4D 的最大逐帧预测差约 0.000239 N；冻结模型在相同接触帧
  MAE 为 0.005825 N，与本次基线接近。差异来自共同排除首帧后训练样本略少。

### 阶段指标的含义

“初触”是每次目标音首次实测接触力达到 0.05 N 后的前 0.12 秒内、有接触的帧。
其余接触帧按过去 1/30 秒的私有真实力变化分为加载（>0.05 N/s）、
稳定（绝对值≤0.05 N/s）和卸载（<-0.05 N/s）。这些仅为离线审计分组，
不代表原生任务已经完成持续保持，也不提供给 agent。
数据持音时间均为 0.12 秒，未验证不同长短音时长。

## 与当前 CaP-X 故障的关系

1. 改善已在专家轨迹上测得，说明面积变化率确实提供了有用的动态信息。
2. 历史 CaP-X 初触 OOD 没有保存原始深度及其历史，无法用本次 5D 模型重放诊断。
3. 在原四维范围不变的情况下，新增第五维盒约束不会消除原四维 OOD。
4. 仍需同一 TACTO 配置下、60 Hz 的 CaP-X 初触同步深度和私有真实力，验证跨策略泛化。
5. 模拟深度由 PhysX 接触几何与真实力共同渲染；这是模拟图像的力反演评估，
   不是独立指尖测力计验证。
